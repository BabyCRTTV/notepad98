# Notepad 98 by 8BitTrade

A free, offline Android text editor with 18 desktop-inspired themes.

- No ads, accounts, analytics, or note uploads.
- Internet is used only for Help → Check for updates.
- Open and save UTF-8 .txt files.
- Font presets, word wrap, find/replace, undo, and local draft recovery.
- Android 8 or newer.

## Browser edition
[Try Notepad 98 in your browser](browser.html). Includes all 18 themes, nine font presets, word wrap, local draft recovery, undo/redo, find/replace, local text-file opening (up to 1 MB), and .txt downloads. Notes stay in the browser; there is no note upload or account service. Save downloads a copy and Rename changes the next download name. Browser drafts are separate from the Android app.

## Browser / Windows 1.8
Open browser.html on the HTTPS site, then choose **Install app** in Edge or Chrome. This is an installable web app (PWA), not a standalone EXE. The editor shell is cached for offline use after the page says Ready for offline use. APK downloads and the landing page require internet. Close all editor windows and reopen online to activate a newly downloaded version. Drafts remain local; download important notes before clearing browser data or uninstalling. Android remains at 1.7.3.

## Check for updates

Windows 1.8.4 and Android 1.7.4 include Help → Check for updates. Updates are checked only on request; neither app uploads notes. A newer release prompts for download, verifies SHA-256, and asks before installation. Android also verifies the package and signing certificate, and uses Android’s installation confirmation. The Windows release workflow publishes the version feed after a successful verified release. Android source and release instructions are in [android/README.md](android/README.md).
