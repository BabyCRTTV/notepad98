# Notepad 98 by 8BitTrade

A free, offline Android text editor with 17 desktop-inspired themes.

- No ads, accounts, analytics, or internet permission.
- Open and save UTF-8 .txt files.
- Font presets, word wrap, find/replace, undo, and local draft recovery.
- Android 8 or newer.
