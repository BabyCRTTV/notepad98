THE USEFUL BITS

A small editor
with the essentials.

  • Open, save, rename. Work with UTF-8 text files using Android’s file picker. Rename depends on the storage provider.
  • Find your words. Undo, cut, copy, paste, select, find, and replace.
  • Make it comfortable. Five font presets, word wrap, and an optional line-and-column status bar.
  • Pick up where you left off. Local draft recovery remembers unfinished text. Save important notes as files.

GET STARTED

On your phone
in a few taps.

  1. Download the APK using the button above.
  2. Open it on your Android phone. If prompted, allow the app opening the APK to install it.
  3. Launch Notepad 98. Type, then choose File → Save.

Requires Android 8 or newer. This is a direct APK download, not a Google Play installation.

Already using an earlier build?

Version 1.7.3 updates 1.7.2 in place. It installs separately from versions before 1.7.2. Save your note in the old app, then open that file in this version. Preferences and unsaved drafts do not transfer automatically.
