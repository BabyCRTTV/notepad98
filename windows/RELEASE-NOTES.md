Notepad 98 for Windows 1.8.1 by 8BitTrade.

- Standalone Windows x64 installer with Start menu shortcut and uninstaller.
- All 17 themes, font choices, undo/redo, find/replace, local file opening and text-file saving.
- The editor is bundled inside the app and works offline from first launch.
- Drafts stay on this computer, separate from the browser and Android editions.
- Save opens a Windows dialog to save a text-file copy. Rename changes the suggested filename.

For Windows 10/11 on Intel or AMD 64-bit PCs. This installer is unsigned; Windows may display an unknown-publisher warning. No code-signing certificate is included.

Android remains at 1.7.3 and the browser edition at 1.8. This release changes Windows packaging only.
