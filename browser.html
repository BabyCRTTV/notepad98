A little desktop nostalgia.

A working browser companion to Notepad 98 by 8BitTrade. Pick any of the 17 themes under View, then start writing.

File → Open reads a local UTF-8 text file (up to 1 MB). File → Save downloads a copy; it does not overwrite the original. Draft recovery and preferences stay in this browser, separate from the Android app.

Shortcuts: Ctrl/Cmd+S to download, Ctrl/Cmd+F to find, Ctrl/Cmd+Z to undo, Ctrl/Cmd+Shift+Z to redo. On a phone, use the menus above.

No accounts, ads, analytics, or note uploads. The hosting provider may log page visits. Independent software, unaffiliated with Microsoft or Apple.
